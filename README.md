# AksiWarga
Platform Smart City berbasis web yang dirancang untuk mewujudkan transparansi layanan publik tanpa sensor, memantau batas waktu SLA instansi secara real-time, dan menyajikan bukti visual penanganan masalah secara akuntabel.
Tech Stack: HTML, CSS, REACT
Cara Menjalan Project: (Clone - Install - Run)
Progress saat ini: Sudah ada landing page dan rekam jejak pengaduan.
